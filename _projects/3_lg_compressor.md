## Overview

- **과제명**: 데이터 기반 컴프레셔 차압 기동 부하 모델링 및 최적제어
- **기간**: 2025.03.01 ~ 2025.12.31
- **발주처**: LG전자
- **역할**: 참여 연구원 → 후반부 실무책임자

전동 압축기 재기동 시 발생하는 차압 기동 부하를 데이터 기반으로 예측하고, 이를 고려한 MPC 제어기를 설계한 프로젝트입니다.

## Key Results

제어기 선형화 및 코드 최적화를 통해 기존 구현 대비 **전체 제어기 연산시간을 93% 단축**했습니다. 이 수치는 제어 구조 변경과 코드 최적화를 함께 적용한 프로젝트 기록 기준입니다.

## Problem

압축기 재기동 시 차압으로 인해 발생하는 부하 변동은 제어 성능과 시스템 안정성에 직접적인 영향을 줍니다. 기존 시뮬레이션은 명목 운전 조건만을 반영하고 있어 차압 기동 상황에서 sim-to-real 오차가 발생하고, 반복적인 검증과 튜닝에 2~3주가 소요되는 문제가 있었습니다.

또한 제어 로직을 실제 적용 가능한 형태로 구성하려면 계산 부담을 줄이고, Simulink 기반 설계를 임베딩 가능한 C 코드 형태로 정리할 필요가 있었습니다.

## Approach

- 전류 및 PWM 데이터로부터 **LSTM 기반 50-step 부하토크 예측 모델** 구축
- **IPMSM dq-axis 모델** 기반 MPC 제어기 설계 (속도 추종 + 전압 제약)
- 연산 경량화를 위해 비선형 제어기를 QP 기반 선형 구조로 전환
- 코드 최적화 및 Simulink Coder를 통한 임베딩용 C 코드 생성
- 모델·제어기 상세설계서 작성 및 현업 엔지니어 대상 기술 인계
- 기존 담당자 졸업 이후 2025년 9월부터 후반부 실무 수행

## Direct Contribution

- LSTM 기반 부하토크 예측 파이프라인 구축
- IPMSM dq-axis 기반 MPC 제어 로직 구현
- 속도 추종과 전압 제약을 고려한 QP 기반 제어 구조 구성
- 제어기 선형화 및 코드 최적화를 통한 연산 부담 감소
- Simulink Coder 기반 임베딩용 C 코드 생성
- 모델예측제어기 상세설계서 작성
- 후반부 실무 담당자로서 과제 진행 정리, 산출물 관리, 코드·문서·기술 설명 인계

## Results and Scope

- 제어기 선형화 및 코드 최적화로 기존 구현 대비 전체 제어기 연산시간 93% 단축
- Simulink Coder를 통해 임베딩용 C 코드를 생성했으며, 실제 임베디드 하드웨어 탑재 및 양산 적용은 별도 검증 범위로 구분
- LSTM 부하토크 예측은 수행 내용으로 표시하고, 확인된 수치가 없는 예측 정확도는 별도 성과로 기재하지 않음
- 후속 산학과제 연계와 LG전자 Target Lab 선정은 연구실 차원의 성과로 구분

## Outputs

- LSTM 기반 부하토크 예측 모델
- MPC 제어기 설계 코드, 임베딩용 C 코드, 모델예측제어기 상세설계서
- 현업 엔지니어 대상 코드·문서·기술 설명 인계
